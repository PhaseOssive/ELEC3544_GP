# v3.1 测试与 v3 结果对比

## 真实运行的根因

核对了指定 v3 目录的 author_verdicts.csv、paper_verdicts.csv、work_evidence.csv、changes.csv，并核对原主表哈希、团队表、Recovery 重验与已接受的序列对齐记录。

v3 的 offline_summary 分支未写 author_name，主流程同时返回空 work_rows。9,428 条空名记录全属于该输出模式，合计检查 1,553,216 个作者位置下的作品。深入核验分支写了其余 633 条作者记录及作品明细。由此可以解释输出缺失，不能据此推断这 9,428 位作者在原始 Recovery 表中也没有姓名，或每次外部核验都因姓名失败。

| 无显示姓名的作者记录 | 9,428 | 0 |
| 全体作者均无显示姓名的论文 | 2,051 | 0 |

633 条沿用已有显示名。9,397 条来自已接受的 Recovery 对齐记录，18 条来自重验元组，13 条来自主表对应位置。20 条保留名单一致性冲突。显示姓名不能作为身份认证。逐行依据见 validation/observed_name_audit.csv。

v3 报告检查 1,662,773 个“作者出现记录 × 去重作品”。实际日志 110,609 行，按 occurrence_id 和 work_id 去重后为 109,557，缺 1,553,216。历史运行修改 1 篇的 4 个单元格。本次没有对真实主表执行正式修复。
